05.10.26 Методы решения систем линейных алгебраических уравнений

① Точные методы
2. Метод Гаусса
• Метод прогонки. (Ax = b) здесь A - трехдиагональная матрица

$\begin{cases}
q_1 x_1 + p_1 x_2 = b_1 \\
p_2 x_1 + q_2 x_2 + p_2 x_3 = b_2 \\
\dots \\
p_m x_{m-1} + q_m x_m + p_m x_{m+1} = b_m \\
\dots \\
p_n x_{n-1} + q_n x_n = b_n
\end{cases}$

$\begin{pmatrix}
\cdot & \cdot & 0 & 0 \\
\cdot & \cdot & \cdot & 0 \\
0 & \cdot & \cdot & \cdot \\
0 & 0 & \cdot & \cdot
\end{pmatrix} = A$

Разделим все уравнения (все $x_i$ и последнее сложнее):
$p_m x_{m-1} + q_m x_m + p_m x_{m+1} = b_m$
$p_m, q_m, p_m$ - известны из матрицы

Пусть $\exists S_m, t_m : x_{m-1} = S_m x_m + t_m$
где $S_m$ и $t_m$ - прогоночные коэффициенты

$p_m (S_m x_m + t_m) + q_m x_m + p_m x_{m+1} = b_m$
$(p_m S_m + q_m) x_m = -p_m x_{m+1} - p_m t_m + b_m$

$x_m = \frac{b_m - p_m x_{m+1} - p_m t_m}{p_m S_m + q_m} = -\frac{p_m}{p_m S_m + q_m} x_{m+1} + \frac{b_m - p_m t_m}{p_m S_m + q_m}$

Т.к. $x_m = S_{m+1} x_{m+1} + t_{m+1}$
$S_{m+1} = -\frac{p_m}{p_m S_m + q_m}, \quad t_{m+1} = \frac{b_m - p_m t_m}{p_m S_m + q_m}$
Рекуррентные формулы для расчета прогоночных коэффициентов

$m = 1: p_1 x_1 + q_1 x_2 = b_1 \Rightarrow x_1 = \frac{b_1 - q_1 x_2}{p_1} = \frac{b_1}{p_1} - \frac{q_1}{p_1} x_2$
$m = 1: x_1 = S_2 x_2 + t_2 \Rightarrow$
$S_2 = -\frac{q_1}{p_1}, \quad t_2 = \frac{b_1}{p_1} \quad \leftarrow \text{Следовательно, значения } S_1 \text{ и } t_1 \text{ (или } S_2, t_2 \text{) находят из первого уравнения}$

$p_n x_{n-1} + q_n x_n = b_n \Rightarrow \text{пусть } m = n \Rightarrow$
$p_n (S_n x_n + t_n) + q_n x_n = b_n$
$(p_n S_n + q_n) x_n + p_n t_n = b_n$
$x_n = \frac{b_n - p_n t_n}{p_n S_n + q_n}$

② Итерационные методы
Здесь приближенно находят $x^{(m)}$ из A:
$\lim_{m \to \infty} x^{(m)} = x^*$, где $x^*$ - решение СЛАУ $Ax = b$

$Ax^* = b$
$\varepsilon^{(m)} = x^{(m)} - x^*$ - погрешность
$r^{(m)} = b - Ax^{(m)}$ - невязка

$r^{(m)} = Ax^* - Ax^{(m)} = A(x^* - x^{(m)}) = -A\varepsilon^{(m)}$
$A\varepsilon^{(m)} = Ax^{(m)} - Ax^* = Ax^{(m)} - b = -r^{(m)} \Rightarrow \varepsilon^{(m)} = -A^{-1} r^{(m)}$

Лемма: Пусть $A = A^* > 0$. Тогда $f(x)$ - квадратичная функция, имеет место задача минимизации $f(x)$ эквивалентна задаче решения СЛАУ.

Док-во: $f \in \mathbb{R}^n, Ax = f$. Пусть $F(x) = x^* A x - 2(f, x) = (Ax, x) - 2(f, x)$; пусть $h \in \mathbb{R}^n$

$F(x+h) - F(x) = (A(x+h), x+h) - 2(f, x+h) - (Ax, x) + 2(f, x) =$
$= (Ax + Ah, x) + (Ax + Ah, h) - 2(f, x) - 2(f, h) - (Ax, x) + 2(f, x) =$
$= (Ax, x) + (Ah, x) + (Ax, h) + (Ah, h) - 2(f, x) - 2(f, h) - (Ax, x) + 2(f, x) =$
$= 2(Ah, x) - 2(f, h) + (Ah, h) =$
$= 2(Ax - f, h) + (Ah, h)$

$grad F = Ax - f = 0 \Rightarrow Ax = f$
$F(x+h) - F(x) = (Ah, h) > 0$

Градиентный метод минимизации $F(x)$
$x^{m+1} = x^m - \alpha_m \nabla F(x) = x^m - \alpha_m (Ax^m - f)$
$x^{m+1} - x^* = x^m - x^* - \alpha_m (Ax^m - f) \quad x^m - x^* = z^m \Rightarrow$
$z^{m+1} = z^m - \alpha_m (A x^m - f) = z^m - \alpha_m (A(x^* + z^m) - f)$
$\Rightarrow z^{m+1} = z^m - \alpha_m (A z^m)$

$\|z^{m+1}\|^2 \to \min \quad (\text{Подбираем } \alpha_m \text{ чтобы это выполнялось})$
$\Rightarrow (z^m - \alpha_m A z^m, z^m - \alpha_m A z^m) \to \min$
$= (z^m, z^m) - 2 \alpha_m (z^m, A z^m) + \alpha_m^2 (A z^m, A z^m)$
$\alpha_m = \frac{(z^m, A z^m)}{(A z^m, A z^m)}$

$\|z^{m+1}\|^2 = (z^{m+1}, z^{m+1}) = (A(x^m - \alpha_m A z^m), \dots)$
$= (z^m, z^m) - 2 \alpha_m (A z^m, z^m) + \alpha_m^2 (A z^m, A z^m) =$
$= \|z^m\|^2 - 2 \alpha_m (A z^m, z^m) + \alpha_m^2 \|A z^m\|^2$

$\alpha_m = \frac{(A z^m, z^m)}{\|A z^m\|^2} \quad \leftarrow \text{метод минимальных невязок}$
